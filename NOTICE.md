# Source and licensing notes

This is a portfolio source repository extracted from the owner's homelab applications. Original source hashes are recorded in `docs/source-provenance.json`; deployment paths, secrets, logs, chat identifiers and runtime data are excluded.

The frozen Pine references were supplied with the original project. Their bytes are retained because runtime and test checks verify their fingerprints. Included reference metadata describes provenance and explicitly unverified parity. Third-party dependencies are installed through pip/npm and retain their own licenses.

No repository-wide redistribution license has been selected. Publication as a portfolio does not itself grant an open-source license. Choose an appropriate license after confirming the rights to all included source and references if broader reuse is intended.
